Sistema de Votación

Descripción
Este es un sistema de votación desarrollado para gestionar elecciones de forma digital, permitiendo el registro de usuarios, creación de candidatos y emisión de votos de manera segura.


Tecnologías utilizadas
- PHP / C#
- MySQL 
- HTML, CSS, JavaScript
- XAMPP (entorno local)


Base de datos
El sistema incluye un archivo SQL para la importación de la base de datos.
Para usarlo:
1. Abrir phpMyAdmin
2. Crear una base de datos
3. Importar el archivo `.sql`

 Cómo ejecutar el proyecto
1. Clonar el repositorio
2. Colocar el proyecto en `htdocs` (si usas XAMPP)
3. Iniciar Apache y MySQL
